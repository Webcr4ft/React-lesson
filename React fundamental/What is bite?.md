# What Is Vite, and How Can It Be Used to Set Up a New React Project?

Unlike working with smaller vanilla HTML, CSS, and JavaScript projects, starting a new React project includes a few more steps to ensure that everything runs correctly.

Instead of trying to set up all the necessary configurations by yourself, there are tools that will do that for you.

## 1. What Is Vite?

**Vite** (pronounced *veet*, meaning "fast" in French) is a build tool that aims to provide a faster development experience for modern web projects.

Vite can be used with React, as well as other libraries and frameworks like Vue and Svelte. You can even use it with vanilla JavaScript projects.

### Why Use Vite?

* **Fast development server:** Starts your development environment quickly.
* **Hot Module Replacement (HMR):** Updates changes in your code in the browser without requiring a full page reload in many cases.
* **Simple setup:** Provides the essential files and configurations needed to start a project.
* **Framework support:** Works with React, Vue, Svelte, and other tools.
* **Optimized builds:** Helps prepare your application for production.

## 2. Creating a New React Project

To create a new project with Vite, you will need to use the command line.

Depending on your operating system, you can use:

* **Windows:** Command Prompt or Windows PowerShell.
* **macOS:** Terminal.
* **Linux:** Terminal.

### Step 1: Install Node.js

If you don't have Node.js installed, you will need to install it before using npm.

**Node.js** allows JavaScript to run outside the browser, while **npm** is a package manager used to install and manage project dependencies.

Visit the official Node.js website:

https://nodejs.org/

Follow the installation instructions, then return to continue setting up your React project.

### Step 2: Create a React Project

Once you have the command line open, run the following command:

    npm create vite@latest my-react-app -- --template react

This command creates a new React project named `my-react-app` using Vite's React template.

### Understanding the Command

* `npm`: Runs the Node Package Manager.
* `create vite@latest`: Uses the latest Vite project creation tool.
* `my-react-app`: Specifies the name of your project.
* `--`: Separates npm arguments from arguments passed to the Vite tool.
* `--template react`: Specifies that you want to use the React template.

Vite provides the essential files and configuration needed to get started with your React project.

## 3. Installing Dependencies

To run the project, you need to install its dependencies.

Run the following commands in your terminal:

    cd my-react-app

    npm install

### Understanding the Commands

**1. `cd my-react-app`**

The `cd` command means "change directory."

It moves you into the project folder where your React application is located.

**2. `npm install`**

The `npm install` command installs the dependencies required to run your React project.

Dependencies are libraries or packages that your project needs to function correctly.

Examples include:

* `react`
* `react-dom`
* Other third-party packages that provide additional functionality.

Running `npm install` reads the `package.json` file in your project directory and installs the dependencies listed there.

## 4. Understanding the `package.json` File

The `package.json` file is an important configuration file in a JavaScript project.

It contains information about your project, including:

* **Name:** The name of your project.
* **Version:** The current version of your project.
* **Dependencies:** Packages required by your application.
* **Scripts:** Commands used to run, build, and manage your project.
* **Other metadata:** Information such as licensing details and project descriptions.

For example, a simplified `package.json` file might look like this:

    {
      "name": "my-react-app",
      "version": "0.0.0",
      "scripts": {
        "dev": "vite",
        "build": "vite build",
        "preview": "vite preview"
      },
      "dependencies": {
        "react": "^19.0.0",
        "react-dom": "^19.0.0"
      },
      "devDependencies": {
        "vite": "^6.0.0"
      }
    }

*Note: This is an illustrative example. The actual versions and configuration generated by Vite may differ.*

## 5. Understanding the `node_modules` Folder

After installing the dependencies, you should notice a new folder in your project called `node_modules`.

The `node_modules` folder stores the packages and libraries required by your project.

It contains the actual code for dependencies listed in your `package.json` file, including dependencies required by those packages.

### Important Things to Know

* The folder is created when you install dependencies.
* It can contain a large number of files.
* You generally should not edit the packages inside it directly.
* It is usually excluded from Git repositories because its contents can be recreated by running `npm install`.

## 6. Running the React Project

After installing the dependencies, you can start the development server.

Run this command inside your project directory:

    npm run dev

Vite will start a local development server and display a URL in the terminal.

It will commonly look like this:

    http://localhost:5173/

Open the URL in your browser.

You should see the starter template that Vite has provided for your React project.

### Stopping the Development Server

If you need to stop the local server, press:

    Ctrl + C

Do this in the terminal where the development server is running.

## 7. Understanding the React Project Files

To view the code for the starter template, open the project folder in your code editor.

A typical Vite React project has a structure similar to this:

    my-react-app/
    ├── node_modules/
    ├── public/
    ├── src/
    │   ├── assets/
    │   ├── App.css
    │   ├── App.jsx
    │   ├── index.css
    │   └── main.jsx
    ├── .gitignore
    ├── index.html
    ├── package.json
    ├── package-lock.json
    └── vite.config.js

The exact structure may vary depending on the template and Vite version.

### Important Files and Folders

**`src/`**

This folder contains much of the source code for your React application.

**`src/App.jsx`**

This file usually contains the main `App` component, where you can start building your user interface.

**`src/main.jsx`**

This file is the entry point that connects your React application to the HTML page.

**`src/App.css`**

This file contains styles associated with the starter `App` component.

**`src/index.css`**

This file contains global styles for your application.

**`index.html`**

This is the HTML page that serves as the entry point for your application.

**`package.json`**

This file stores project information, dependencies, and scripts.

**`package-lock.json`**

This file records the specific dependency versions resolved by npm to help maintain consistent installations.

**`node_modules/`**

This folder contains installed packages and their dependencies.

**`vite.config.js`**

This file contains configuration options for Vite.

## 8. Modifying Your First React Component

Once your project is running, open the `src/App.jsx` file.

You can replace its contents with the following example:

    function App() {
      return (
        <div>
          <h1>Hello, React!</h1>
          <p>My first React application using Vite.</p>
        </div>
      );
    }

    export default App;

Save the file.

Your browser should automatically update to display the new content.

This happens because Vite supports Hot Module Replacement (HMR), which helps apply code changes during development without requiring a full page reload in many cases.

### Understanding the Code

* `function App()` defines a React functional component.
* `return` specifies the JSX that the component renders.
* `<div>` groups the heading and paragraph.
* `<h1>` displays the main heading.
* `<p>` displays the paragraph.
* `export default App` makes the component available for import into another file.

## 9. Common Commands to Remember

| Command | Purpose |
|---|---|
| `npm create vite@latest my-react-app -- --template react` | Creates a new React project using Vite. |
| `cd my-react-app` | Moves into the project directory. |
| `npm install` | Installs the project's dependencies. |
| `npm run dev` | Starts the development server. |
| `npm run build` | Builds the project for production. |
| `npm run preview` | Previews the production build locally. |
| `Ctrl + C` | Stops the running development server in the terminal. |
